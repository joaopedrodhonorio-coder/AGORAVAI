# Site do Grupo Turing

Site acadêmico do Grupo Turing, do curso de Engenharia da Computação. Apresenta o grupo, seus integrantes e projetos.

O site é hospedado pelo GitHub Pages. Os projetos publicados e suas mídias são armazenados no Supabase. Assim, o administrador pode gerenciar o conteúdo pelo próprio site, sem editar o código para cada atualização.

## O que o site oferece

- Apresentação do grupo e de seus integrantes.
- Seção **O que já criamos**, com os projetos publicados.
- Seção **Nossos momentos**, que inclui o acesso privado para administrar projetos.
- Cadastro e edição de título, apresentação, fotos e vídeos.
- Remoção de projetos pelo painel do site.
- Exibição pública dos projetos para os visitantes.

## Tecnologias

- HTML
- CSS
- JavaScript
- GitHub Pages
- Supabase Database
- Supabase Storage
- Supabase Auth

## Estrutura do repositório

- `index.html` — estrutura e conteúdo das seções do site.
- `style.css` — aparência e layout responsivo.
- `project-admin.js` — login do administrador, exibição e gerenciamento dos projetos.
- `supabase-setup.sql` — configuração da tabela, do armazenamento e das permissões no Supabase.
- `imagens/` — imagens utilizadas no site.
- `videos/` — vídeos utilizados no site.

## Publicação no GitHub Pages

1. Abra o repositório no GitHub.
2. Acesse **Settings → Pages**.
3. Configure a publicação pela branch `main` e pela pasta raiz (`/`), se ainda não estiver configurada.
4. Salve e aguarde o GitHub concluir a publicação.
5. Copie o endereço do site exibido em **Settings → Pages**.

Depois da configuração, atualizações no código enviadas à branch publicada são disponibilizadas pelo GitHub Pages. O endereço costuma seguir este formato:

`https://USUARIO.github.io/NOME-DO-REPOSITORIO/`

Use o endereço exibido nas configurações do repositório para confirmar a URL correta.

## Configuração do Supabase

O arquivo `supabase-setup.sql` cria ou atualiza a tabela dos projetos, configura o armazenamento de fotos e vídeos e define as permissões de acesso.

Para executar a configuração:

1. Abra o projeto no Supabase.
2. Acesse **SQL Editor** e crie uma nova consulta.
3. Copie todo o conteúdo de `supabase-setup.sql` e cole na consulta.
4. Clique em **Run** e confirme que a execução terminou sem erros.

O script foi preparado para poder ser executado novamente. Ele adiciona os novos campos e permissões, preservando os registros existentes.

## Configuração do login

No painel do Supabase:

1. Acesse **Authentication → URL Configuration**.
2. Configure o endereço publicado pelo GitHub Pages como **Site URL**.
3. Adicione o mesmo endereço em **Redirect URLs**.
4. Salve as alterações.

O link de autenticação enviado por e-mail redireciona de volta ao site. O endereço precisa estar permitido no Supabase para que o login funcione.

## Como administrar projetos pelo site

1. Abra a seção **Nossos momentos** no site publicado.
2. Digite o e-mail autorizado e solicite o link de acesso.
3. Abra o link recebido no mesmo navegador.
4. No painel de administração, escolha **Adicionar projeto** ou edite um projeto existente.
5. Preencha o título e a apresentação. Para substituir as mídias de um projeto, selecione as novas fotos ou vídeos.
6. Salve as alterações.

Os projetos atualizados aparecem na seção **O que já criamos**. Visitantes podem visualizar o conteúdo, mas apenas o administrador autorizado pode adicionar, editar ou remover projetos.

O limite configurado no Supabase é de **50 MB por arquivo**.

## Segurança

As permissões são aplicadas pelas políticas de segurança configuradas em `supabase-setup.sql`. A chave `sb_publishable_` usada pelo site é uma chave publicável; as regras no Supabase controlam o acesso aos dados e às mídias.

Nunca coloque no código ou no repositório:

- Chaves `secret` ou `service_role`.
- Senhas do banco de dados.
- Tokens privados.

## Solução de problemas

- **Os projetos não aparecem:** confira se `supabase-setup.sql` foi executado sem erros.
- **O link de login não retorna ao site:** verifique se a URL publicada está em **Site URL** e em **Redirect URLs** no Supabase.
- **O site ainda mostra a versão antiga:** confira o status de publicação em **Actions** ou **Settings → Pages** no GitHub e atualize a página depois que a publicação terminar.
- **Uma mídia não é enviada:** confirme se o arquivo é uma foto ou um vídeo e se tem até 50 MB.
